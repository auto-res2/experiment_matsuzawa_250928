PASHA extends ASHA by incorporating a progressive resource allocation strategy, inspired by the 'doubling trick'. This ϵ value is automatically estimated by measuring noise in rankings, specifically by identifying 'criss-crossing' behaviors between pairs of configurations across different resource levels (epochs), indicating similarly performing configurations.
