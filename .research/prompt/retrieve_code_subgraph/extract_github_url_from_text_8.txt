DyHPO is a Bayesian Optimization approach built on Gaussian Processes (GP). It employs a novel deep kernel, K(θ, w), which uses a neural network φ to extract features from hyperparameter configurations, budget information, and the learning curve. The neural network φ consists of linear and 1D convolutional layers followed by global max pooling. The optimal kernel and neural network parameters are found by maximizing the marginal likelihood using gradient descent with Adam. A multi-fidelity Expected Improvement (EIMF) acquisition function guides the search, dynamically setting the budget for the next configuration to explore by incrementing it from the last evaluation. The algorithm iteratively selects the most promising candidate to train for a small additional budget, updating the surrogate model with new observations.
