# Paper Outline
ColaBO operates by introducing an augmented user belief over function properties, such as the optimum or optimal value, which reshapes the Gaussian Process (GP) prior to reflect these beliefs. It deviates from typical Gaussian posterior assumptions and uses rejection sampling on draws from the GP prior to form a 'belief-weighted prior' (p(f|ρ)). When observations (D) are obtained, the posterior (p(f|D, ρ)) is updated using a pathwise update (Equation 8) that preserves the shape of the belief-weighted samples far from observed data. This non-Gaussian, belief-weighted posterior is then used with Monte Carlo (MC) acquisition functions (e.g., Expected Improvement (EI), Max-Value Entropy Search (MES)) by re-sampling functions proportionally to their probability under the user belief. This biases the acquisition function to direct the search towards regions consistent with the prior.
