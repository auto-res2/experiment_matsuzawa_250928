# Paper Outline
PASHA extends the ASHA algorithm by incorporating a dynamic resource allocation mechanism inspired by the "doubling trick". It starts with a small initial amount of resources and progressively increases them only if the ranking of configurations in the top two rungs has not stabilized. A core component is "soft ranking," which considers configurations equivalent if their performance difference is below a threshold ϵ. This ϵ value is automatically estimated by measuring noise in rankings: it identifies pairs of configurations that repeatedly swap ranks across different resource levels (epochs) and calculates ϵ as the N-th percentile of performance differences for these "criss-crossing" pairs. PASHA uses a reduction factor η (similar to ASHA) to prune candidates and includes a user-defined maximum resource R as a safety net, beyond which it defaults to ASHA.
